# Mall Customer Segmentation (K-Means)
Segmenting mall customers by annual income and spending score using K-Means.

- Notebook: `Mall_Customer_Segmentation_KMeans.ipynb`
- Data: Kaggle, vjchoudhary7, *Customer Segmentation Tutorial in Python*
- Steps: EDA, scaling, elbow + silhouette for K, training, cluster profiling, bonus (NumPy K-Means and 4-feature comparison)
